## 一、用豆包工作模式 / 扣子（Coze）搭 Agent 接企业自动化单

### 案例 1：13 岁女孩吕思彤用扣子做"青蛙外教"，自称接百万商单
1. **案例标题**：13 岁女生用扣子（Coze）做 AI 英语陪练，登豆包发布会
2. **当事人/账号**：吕思彤（家庭公开采访）
3. **工具**：字节扣子 Coze（低代码智能体搭建）；产品"青蛙外教""小狐狸讲代码"
4. **做了什么**：不懂编程，在扣子上拖拽搭建 24 小时在线 AI 英语陪练，积累几万用户；后做"小狐狸讲代码"（把变量解释成"装蔬菜的冰箱"），中英日三语，拿亚马逊云科技全球赛道名次
5. **获客**：产品自然流量 + 登上豆包大模型发布会曝光
6. **定价/收入**：自述"一个商单最低几万、最高几百万"，已承接企业/个人开发订单；**但截至发稿，字节、AWS、学校及权威媒体均未对"百万商单"金额做官方背书**
7. **实操工作流**：在扣子可视化画布拖节点 → 接豆包大模型 → 配知识库/插件 → 一键发布到豆包/微信
8. **证据强度**：**B（产品真实存在、登发布会为真）/ C（百万商单金额为当事人单方说法）**
9. **来源**：https://cj.sina.com.cn/articles/view/7879849863/1d5acf78706801vaw2 ；https://cj.sina.com.cn/articles/view/7879777296/1d5abdc1006801dhdk
10. **可复制性点评**：扣子拖拽搭建门槛极低，但"百万商单"不可复制；可复制的是"把一个垂直场景（少儿英语）做成小智能体 + 借发布会/大赛曝光"。

### 案例 2：闲鱼"上门装小龙虾智能体"远程部署一条龙
1. **案例标题**：闲鱼兴起"上门安装 AI 智能体"产业链
2. **当事人/账号**：闲鱼多位匿名卖家（无统一 ID）
3. **工具**：扣子 Coze / 开源智能体（"小龙虾"类本地模型）
4. **做了什么**：远程一键部署智能体、同城上门调试、打包零基础保姆教程、出租适配高配置设备
5. **获客**：闲鱼挂单（C2C 无保证金）+ "上门安装小龙虾智能体"热搜自然流量
6. **定价/收入**：几十元入门教程、一两百元远程安装、数百元定制部署与包月维护；巅峰期相关搜索量暴涨 1850%
7. **实操工作流**：客户下单 → 远程协助装环境 → 配好模型与工作流 → 交付文档 + 包月答疑
8. **证据强度**：**B（钛媒体/脑极体实地调研，闲鱼官方数据）**
9. **来源**：http://news.qq.com/rain/a/20260824A05VCO00
10. **可复制性点评**：典型"卖铲子"生意——赚的是下沉市场"不会装"的信息差；工具一旦官方出一键安装，生意即死。

### 案例 3：豆包做内容电商，一人一天 30 篇小红书帖，公司从 1 人到 20 多人
1. **案例标题**：失业人做 AI 偷赚 200 万（话术）/ 豆包批量产小红书内容
2. **当事人/账号**：抖音视频转述的"朋友公司"（匿名）

### 案例 4：豆包工作模式接香薰品牌商单，并行做报价/扒档期

## 九、典型标题党套路识别

> 结合 V2EX、黑猫投诉、新湖南/政府防骗提示、抖音拆解视频，归纳如下：

1. **"用豆包/TRAE 三天赚十万""AI 编程小白月入过万"**——闲鱼官方数据显示 AI 卖家人均月成交额仅 **897 元**（981.6 万单 ÷ 海量卖家）。晒"月入过万"的几乎都是全职深耕、审美/技术过硬的头部；新手面对的是 9.9/19.9 元小单 + 反复改稿。
2. **"卖 vibe coding 课年入 1000 万"**——V2EX 高赞拆穿：真能靠 vibe coding 赚 1000 万的人，不卖课也能赚；他赚的是"看你眼热来私信"的钱，本质是卖 token/卖课的信息差。
3. **晒图常见伪造/误导手法**：
   - 把"流水"当"利润"（周琳、杨波都主动提醒：流水十几二十万，扣师资/算力/课件后净利有限）；
   - 把"广告消耗后的 GMV"当"收入"；
   - 用 App Store 后台"销售额"截图不扣苹果 30% 抽成和退款；
   - 拼微信收款小账本截图（可 PS、可凑单日而非月累计）；
   - "3 个月 8 万""落袋 50 万"无合同、无对公流水、无连续月份截图。
4. **培训割韭菜标准剧本**（新湖南/武汉东西湖区警方提示）：
   - 直播间"零基础轻松月入过万、包教会、包接单、3-4 周安排单"→ 先交 2690 → 顾问说"技术太差要上高阶课"5000/8000/10000 层层加 → 电子合同写"开课只退 10%"。
   - 黑猫投诉：知乎知学堂类被指虚假宣传"包接单"却不派单。
   - 警方口径：凡说"AI 轻松月入过万、躺赚、全自动赚钱"→ 100% 骗局；"先交钱再培训诱导贷款"→ 99% 是坑。
5. **"上门装 AI/智能体"猎奇流量**——热度高但生命周期短，平台/官方一旦出一键安装，卖家立刻被架空。
6. **识别口诀**：要看"连续 6 个月以上的到账曲线 + 客户/合同 + 自己也在做真实交付"，而不是单张收款截图；凡是"先让你交钱教你赚钱"的，先假设对方赚的就是你的学费。

## 十、国产工具 vs Cursor / Claude 的真实差异（从赚钱效率角度）

> 不是功能罗列，只讲对"接单/做产品赚钱"有影响的差异：

1. **成本结构**：这是国产工具最大的赚钱优势。Kimi/DeepSeek/通义等 API 价格约为 Claude Sonnet 的 1/6、GPT-5/Opus 的 1/20-1/30。做 Listing 批量（840 条 47 元）、做机构交付（案例 38）时，国产模型直接决定毛利。Cursor Pro 约 $20-200/月，国产通义灵码个人版免费、CodeBuddy 约 $10/月、Trae/扣子有免费额度——**新手试错成本接近零**。
2. **中文场景与合规**：写体制内述职、小红书文案、亚马逊中文转英文、国内小程序/微信生态（流量主/虚拟支付），国产工具（豆包/扣子/Trae 读中文截图）更顺手；扣子可一键发布到豆包/微信，省去海外部署和 Stripe 收款门槛。
3. **生态与获客闭环**：扣子/Trae 有官方社区 + 大赛（TRAE SOLO 挑战赛）+ 微信小程序成长计划（免费云开发、1 亿 token、广告免开发接入），做小程序能直接吃到平台补贴；Cursor/Claude 做的是英文 SaaS/Chrome 插件，要自己搞定海外支付、SEO、Stripe，门槛高但客单价高（MRR 美元）。
4. **能力边界**：做生产级复杂系统（票务分账、RBAC、多渠道发布）时，头部案例里仍有相当比例叠加 Claude Code/Cursor 做兜底（案例 5 老手"Cursor/Claude Code"，案例 13 成本对比用海外工具）。国产工具在"快速出 MVP、读截图生成 UI、中文长任务"上追平，但极复杂工程链路的稳定性仍需工程判断力兜底。
5. **变现路径差异**：国产工具更适合"国内小额高频服务 + 微信小程序流量主 + 企业内训/陪跑"（客单几十到几万，人民币结算，获客靠闲鱼/小红书/抖音）；Cursor/Claude 更适合"出海 SaaS/Chrome 插件/海外 Fiverr 接单"（MRR 美元，获客靠 Product Hunt/SEO）。
6. **一句话**：国内普通人抄，先用免费/便宜的国产工具把"需求验证 + 微信生态交付"跑通；要赚美元再叠加海外工具做出海产品。不要为了用 Cursor 而用 Cursor——成本会吃掉早期本就微薄的利润。

## 十一、国内普通人最容易抄的 3 个路径（≤5 行）

1. **小红书验需求 + Trae/扣子做长尾小程序 + 微信流量主**：发笔记看评论区追问 → 1-2 天 AI 做 MVP → 500 访客开封面广告（0.5 元/次是大头），矩阵 10-15 个跑通 5-7 个，对标月入 2 万（案例 5）。
