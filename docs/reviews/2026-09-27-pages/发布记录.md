# GitHub Pages 发布

需求：将现有项目托管于 GitHub，并提供可访问的网站。

设计：保留原仓库 main；GitHub Actions 先检查、根路径构建和现有验证，再按 /Vibecoding-guide 构建 Pages 产物。站点 URL、前端返回链路、首页继续学习和全文搜索适配子路径；旧 public 资源路径在独立部署构建后规范化。普通本地构建仍使用根路径。Pages 使用 HTTPS，不新增第三方托管或自定义域名。

上线目标：https://rouicezar.github.io/Vibecoding-guide/zh-cn/

参考：https://docs.astro.build/en/guides/deploy/github/ 与 https://docs.github.com/en/rest/pages/pages 。
