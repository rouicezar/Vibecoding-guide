# 模拟初学者试走：断点与修正

身份与范围：编辑者模拟，未招募真实学员，未把 AI 的知识当作初学者理解能力。独立预览端口 4341 使用测试草稿，不改用户 4339 的学习记录。网站交互实测与教程内容审查分开记。

| 断点 | 依据 | 修正 |
|---|---|---|
| 第一页指向不存在的字段 | 03 写“现在有什么麻烦”，实际只有一个文本框中的四个问题 | 使用实际问题名称，先指出 07 输入框，说明保留问题、替换括号内容 |
| 填草稿却被称为发给 AI 的话 | 想法和描述页的 07 标题、模板标题与用途不符 | 07 改为“本步材料（填写或复制）”；填写型模板使用“填写模板”，说明何时交给工具 |
| 返回描述页后不知道怎样复制 | 浏览器返回保留编辑稿，但需要再次确认才显示复制按钮 | 补充重新确认与复制方法，提醒不要用新版模板覆盖自己的填写 |
| 短提示词放出来后，缺发送方法 | 03 只有文本框，无说明如何使用 | 在已有正文处说明选中复制、切到工具、替换空白、发送、等结果、再继续 |
| 网页工具被要求用本机快捷键与路径 | folder/open-project 的第二和第三动作未区分工具类型 | 分别说明电脑文件夹与网页工作区操作，填写位置后确认 |
| 空文件夹直接跳到装依赖和运行 | environment 缺少最小配置与启动文件的建立 | 先检查已有文件，缺少时按已选方案创建，再安装必要程序包 |
| 通用保存教学强制后端与数据库 | save 的后续动作默认后端、列表和跨浏览器共享 | 明确按已选设计走，无保存、浏览器保存、后端数据库分别处理；跨浏览器核对只用于共享存储 |
| 恢复演练没有教新增什么、在哪里新增 | maintain 要检查“这次新增”，但短提示词没包含实际新增操作 | 明确打开恢复副本、保存独特测试内容、填写记录编号、只读核对原库；无数据库项目跳过数据库演练 |

## 实际网站操作

1. 首页“开始第一步”进入想法页；填写四个问题，确认生成成功。
2. 用步骤底部入口进入描述页；点击“带入前面已确认的材料”，实际带入使用者、问题、测试条件和第二阶段选择。
3. 补齐名称、设备、使用过程和预算，确认生成；复制反馈显示“已复制”，读取本次复制结果与测试项目名称匹配。首次读取发生在反馈完成前，没有据此判断复制失败。
4. 返回描述页，自己的文字仍在；再次确认可以重新复制。未修改模板保存脚本。
5. 读取其余 15 个节点的实际页面内容（包括其中的修复步骤），逐项对照当前操作；证据为 browser-before.json。这是内容检查，不是完成安装、注册、开发或发布。
6. 修正后重新检查第一步、填写模板及发送说明；截图见 idea-after.png。
