# 零基础试走记录（待真实使用者填写）

状态：未开始。参与者称呼：____；日期：____；电脑系统：____；使用工具：____。

给参与者的任务：按网站步骤，用你选择的工具做一个自己用的学习记录项目。先在电脑上使用即可；它应能填写、保存和重新找到记录。你可以随时停止，不需要购买服务。请边做边说你以为下一步该做什么。

观察者先不解释页面。学员找不到、读不懂或主动求助时，先记录原话和页面位置，再提供帮助；记录帮助内容。不要诱导学员复述教程用语，也不要替他填写“完成”。

每段结束时只问三个问题：你刚才做了什么？在哪里看到结果？如果下次结果不同，你会从哪里找帮助？保留原话，不代答。

结束时记录：独立完成到哪里；在哪些动作获得帮助；项目实际入口；保存后重开能否找到记录；仍需修改的教学位置。没做的项目写“未测”，遇到失败写实际现象。
