## 验证范围

- `npm run check`：0错误、0警告，7条既有提示（旧示例类型、废弃API等）；不宣称清除无关代码提示。
- `npm run build`：静态构建及搜索索引。
- `npm run verify`：2208双语页面、路由/资源、31步、模板、资料库与755术语的现有检查；新增项目隔离、全备份、非覆盖恢复、双语默认模板拒绝、文件契约及术语链接回归。
- 浏览器使用独立4336来源的测试资料，不触碰用户4324来源草稿。
- 想法→描述→项目起点：用户/问题/通过条件只填一次，经明确带入按钮传递；保留本步新增输入。
- 沟通页：空表单确认按钮禁用；填写后生成可复制内容。
- 备份：包含想法、描述、起点模板、沟通表单与生成模板；文本恢复建立新项目并保留原项目与第二项目。
- 首页：提前浏览第28步后，继续入口仍为第2步；最近浏览单独提供。
- 平台：iPhone点击后选中并修改提示词；稳定构建后刷新仍选中。曾在构建替换静态资源期间观察到脚本未生效，完整构建结束后重新验证通过。
- 人工核对：未测试时点击验收通过入口被阻止，提示填写实际版本与结果。
- 备份下载事件在当前自动化浏览器未返回文件路径；未声称实际文件下载已验证。文本备份/恢复路径已实际验证，JSON解析及文件恢复核心逻辑有回归覆盖。

## 证据边界及后续验收

本次验证模板结构、上下文交接、范围边界、页面交互和回归；没有向外部AI工具发送真实开发任务，没有开发/发布覆盖所有平台的样例，也没有真实零基础用户独立完成证据。因此48项均有实施位置，但不把它们写成“新手目标全部验收通过”。
