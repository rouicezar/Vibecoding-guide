# 首页视觉整改

目标：首屏清楚表达从想法到作品的收益，只有一个主要开始/继续按钮；降低首页阅读负担。

现状：文字集中在左侧、右侧空白，首屏后直接堆入旧知识地图，主学习流程辨识度不足。

设计：参考用户此前提供的彩色曲线路线图，用白底、彩色细线与圆形节点串联想法、描述、作品。首屏左侧说明与行动、右侧原创流程示意；下方六阶段只显示动作与产物并链接真实阶段，完整地图进入独立页面。保留历史锚点兼容、继续学习与双语。避免虚假成品试用、自动循环动画和大块彩色填充。

验证：类型检查、构建、全站静态检查；浏览器核对桌面及320/768/1024/1440宽度、入口与键盘焦点、双语。美感由用户预览验收。

## 用户文案与背景调整

按用户指定原文替换首页标题、说明与阶段标题，英文同步语义。新增本地SVG点阵与浅色路径背景，避免依赖外部图片；调整长标题字号及自然换行。旧中性文案规则只对本次首页指定的两处含“你”文本做精确豁免，不扩大到其他页面。
