# 新手学习路径整改实现与验收

## 需求与设计

依据 `docs/beginner-rectification-plan.md` 和本次用户补充：UI 必须清晰、模块化、层级化，避免每页堆满资料。使用完整版本工作树实施，旧目录预览不作为基线。

- 首页只保留一个开始/继续入口、路线入口和可试用的小作品。
- 六个阶段为父层，22 个动作为子层，问题列表与具体排障为更深层，均可直接链接。
- 每个动作显示位置、操作示意、必要动作、成功依据与两个明确出口。长提示词、示例、扩展资料按需展开。
- 目录与文件定位用结构示意；示意不冒充真实工具截图。保留文字替代信息和键盘路径。
- 旧资料库、212 个组件、双语和旧阶段链接保留。学习主线与资料入口分离。
- 进度为手动确认，草稿与进度仅在浏览器本地保存；不把阅读、标记完成或测试通过当作真实新手验收。

## 已实现

- 阶段 → 动作 → 问题 → 解决方法的独立页面，以及原动作返回路径。
- 想法草稿保存、恢复、导出；保存失败明确提示；读取异常不覆盖原记录。
- 给 AI 的提示词带入已有想法；资料页保留返回上下文。
- 提示词生成器材料改变后禁用旧文案复制；刷新恢复输入。
- 技术选型结果与已选条件进入交接提示词，条件变化后必须更新。
- 当前浏览器 / 多设备共享 / 无需保存三条资料检查分支。
- 可实际输入、保存、刷新验证的中英文学习记录示例。
- 新步骤与问题加入静态路由和全文索引；快捷搜索默认最多六项。

- `npm run verify`：610 个双语地址、语言对应页、单一主标题、站内资源/锚点、212 词条逐字段对照、选型条件及学习状态测试通过。
- 浏览器实测：想法填写后刷新恢复；提示词中包含草稿；文件缺失三级求助并返回原动作；中文问题搜索直达对应问题页；本机保存分支；资料页返回上下文；英文对应页；旧 `#stage-ui` 导向新动作。
- 浏览器实测：选型条件进入交接材料；修改条件后禁用旧提示词复制；沟通表单生成后可复制、修改后禁用、刷新恢复修改内容。
- 成品示例实测：空白提交提示、正常保存、刷新后记录仍在。
- 文件定位页在 320 / 768 / 1024 / 1440 宽度下 `scrollWidth === innerWidth`；长说明默认收起。手机首页与求助页、桌面首页/阶段/动作截图保存在本目录。

安装/登录使用官方说明入口和示意，未执行全新账号安装，未声称验证所有平台界面。未进行五位真实零基础用户研究，R6 的独立完成率待实测。仓库推送不等于网站公开部署。

## 第二轮：完整路线图、返回与视觉层级

用户明确要求保留完整路线图与知识覆盖。本轮以 13 主节点、3 制作分支为导航骨架，四个有序色彩分区呈现。首页和主导航均提供路线图；每个节点以五组按需展开的内容接回原动作、输入、例子、疑问、完整模板、资料及原排障。小步骤辅助操作，不再替代原路线。

返回以实际入口链为准，链随本地站内 URL 保留，刷新/新标签页仍可回到入口；直接访问时提供结构上的父页。语言切换保持对应路径。交互使用轻量点击反馈、展开/收起高度过渡及页面淡入，支持减少动态效果偏好。字号、深色主标题、弱化辅助文字与阶段强调色建立视觉层级。


第二轮验证：`check` 50 文件无错误/警告；`build` 和 `verify` 通过，644 双语页，16 原节点与对应原排障模板可达。浏览器验证了路线节点→风格资料→返回原展开区域、刷新入口保持、资料库→项目分类→Web详情→返回分类。观察到收起期间保留 open 且有过渡状态，随后完全闭合。390 宽度路线图与节点页无横向溢出，路线图含全部 16 节点。

依据用户补充移除装饰性彩色上边/左边线，使用轻底色、标题字号与文字颜色区分层级；路线连接线保留表达流程关系。新截图：`roadmap-desktop.png`、`node-mobile.png`。

配色跟进：按用户要求，将灰蓝/棕灰阶段色改为正红、橙、青柠绿、黄色。鲜色集中在阶段编号、图标和主行动，浅底色辅助分组，正文保留深色；不恢复装饰色边线。红底白字编号/按钮对比度 4.52:1，橙/青柠/黄底配深色编号分别为 6.38、8.68、9.89:1。
