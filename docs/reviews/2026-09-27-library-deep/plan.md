# P42 资料库深入整改

目标：每页能回答何时用、为何这样做、实际怎么做、怎样判断完成、失败如何处理。保留既有材料，不以统一空泛说明充数。

实施：
1. 为212个组件恢复对应示意，区分外观与交互；旧演示独立隔离、不连接业务。修复日期、浮层、复制、数据展示等会误导的行为，提供每类操作说明和边界，保留原始规格供核对。
2. 将组件模板中的含糊填写语句改为可校验占位字段；示例品牌和文案不自动成为项目需求。
3. 资料页提供针对当前判断的材料清单、决策任务、结果检查，替换借用整阶段任务的提示词；校正不适用状态与返回入口。
4. 构建/结构检查覆盖全部页面与演示映射；浏览器验证实际状态变化、模板校验和移动布局。示意不能冒充生产实现、外部工具成功或独立学习效果。
