## 已执行验证

- 干净安装：`npm ci`，Node 26.7.0。新增开发依赖锁定具体版本。
- 格式、静态规则、Astro/TypeScript 检查、状态单元测试通过。
- `npm run build && npm run verify`：现有16组全站校验全部通过。
- `npm run build:pages`：2,383份HTML的子路径链接/资源存在性通过；输出独立 `dist-pages`，不替换根路径预览。
- 内容迁移等价：31个步骤、86个双语操作及其提示词、结果、恢复内容保持原值；移除的旧 actions 摘要没有页面消费者，兼容API改为派生当前指引。见 [内容对比](content-equivalence.txt)。
- 浏览器：桌面1280宽、手机390宽；根路径4342、正式子路径4343。共享场景通过实际页面按钮和输入框执行；搜索实测返回60项，子路径结果地址带 `/Vibecoding-guide/`。
- 视觉：见 [比较结果](visual-comparison.json) 和 [页面截图](verified-page.png)。项目下拉框及选项随测试项目名称变化，不纳入逐元素对比；选择框随新名称自然从201px变为245.5px，其余466个元素一致。
- 官方 npm 注册源审计：0个已知漏洞。未对 Python 示例做新增漏洞扫描。

## 运行与剩余边界

执行入口和维护规则见 [工程约定](../../engineering.md)。新的CI浏览器配置可发现12例（6场景×2视口），再分别对根路径与正式子路径运行；本地使用CUA执行相同共享场景，不把仅完成测试发现算成浏览器通过，也不冒称远端CI已运行。

自动检查和编辑者操作不等于零基础学员能够独立完成项目。下一步继续按现有真人试走表收集首次断点，必要时仅调整对应步骤和资料。
