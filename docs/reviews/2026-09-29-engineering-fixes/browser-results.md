# 实际浏览器检查

本地通过 Codex CUA 操作真实页面；测试材料均使用独立4342/4343端口，不清空或编辑用户4339的材料。

共享场景来源：`tests/browser/scenarios.mjs`；CI驱动：`tests/browser/core.spec.mjs`。以下是本轮实际观察记录，不是远程Playwright报告。

| 场景 | 观察结果 |
| --- | --- |
| 折叠恢复 | 关闭03并刷新仍关闭；打开第二个操作并刷新仍展开；外层步骤关闭后刷新不被默认逻辑重新展开；带锚点进入能打开目标 |
| 两标签项目隔离 | A、B分别创建草稿；A旧页继续写入后，B刷新保持B原文；切回A看到A最新内容 |
| 模板 | 确认后可复制，修改后复制禁用；刷新恢复最新草稿；切换英文到同一步骤 |
| 视觉约定 | 主按钮白字；输入框和下方按钮至少16px间距；焦点无蓝色环；390px宽无横向溢出 |
| 搜索 | 根路径和Pages子路径，桌面与390px宽均可搜索Git并返回60项；子路径结果为 `/Vibecoding-guide/zh-cn/terms/github/` |
| 恢复备份 | 不完整JSON显示错误且保留当前项目；有效备份建立新的恢复项目，显示备份里的想法原文 |

折叠、两标签、模板和视觉场景在桌面/390px、根路径/Pages子路径组合实际通过。备份恢复在根路径桌面、Pages桌面及390px实际通过；存储写失败用状态单元测试逐次注入。

测试工具初次遇到刷新时机和同页多个模板选择器问题，已将刷新等待、状态等待和模板作用域固化到共享场景，并重新实测通过。没有通过跳过断言掩盖失败。

独立端口中的 Audit / Browser restore 项目均为测试数据。测试页面在本轮结束时关闭。全站真实零基础学员试走未执行。
