# 学习记录练习：执行边界与设计

这是本次体验的隔离练习，不是本站新增功能，也不是真实新手验收。

需求来自本站沟通表单实际生成的 `../generated-prompt.txt`：只给自己用，输入学习内容、保存、查看，刷新后保留；空内容提醒；Mac、零预算、不登录、不同步、不发布。

设计由执行 AI 补充：单页 HTML、浏览器本地保存、仅本机 HTTP 预览。这些具体实现选择不是学习者从站内学会的，也不是选型表单直接生成的方案。保存仅限同一浏览器和同一地址；清理浏览器数据会丢失，不能当作可靠长期备份。

本站给出的流程用于约束任务：先确认范围，再做一个小版本，再检查正常和失败情况。本站并没有给出这个项目的现成代码。

运行：在此目录执行 `python3 -m http.server 4337 --bind 127.0.0.1`，访问 `http://127.0.0.1:4337`。这是执行 AI 提供的命令，不能当作教程已覆盖 Python 安装。

检查计划：空白提交被阻止；中文记录提交后出现；刷新仍保留；关闭后重新打开同地址仍保留。未测试浏览器存储配额、浏览器数据损坏、真机、跨浏览器或公开部署。
