# Tool selection review sources

Checked 2026-09-23. All summaries are paraphrases. Historical reports describe their own versions, not verified present-day defects.

1. [Ars Technica: four coding agents build Minesweeper](https://arstechnica.com/ai/2025/12/the-ars-technica-ai-coding-agent-test-minesweeper-edition/) — independent hands-on comparison, 2025-12-19
   Evidence: Authors supply shared prompt, blind judging and playable outputs. Codex completeness and Claude presentation/speed differ; Gemini configuration lacked newer models.
   Limit: Single task, historical versions, subjective scoring; 100-word source summary budget.

2. [TRAE 社区：我的 AI Coding 启蒙经历](https://forum.trae.cn/t/topic/175108) — first-person community report, 2026-08-10
   Evidence: Author describes choosing the readable GUI, an embedded project taking two months and many iterations, and later continued use.
   Limit: Self-report in an incentivized story campaign; linked external project not independently reproduced.

3. [Cursor forum: Questions from a new](https://forum.cursor.com/t/questions-from-a-new/148900) — official forum user question and response, 2026-01-14
   Evidence: New user cannot reconcile free Agent mode, usage dashboard and plan prices.
   Limit: Use as evidence of onboarding confusion, not current price authority or exact mode semantics.

4. [Qoder is amazing! Any chance for a small credit boost?](https://forum.qoder.com/t/qoder-is-amazing-any-chance-for-a-small-credit-boost/1876) — official forum user experience, 2025-09-10
   Evidence: Users praise IDE and speed while questioning credit consumption; staff replies mention future adjustments.
   Limit: Early pricing period; no current cost comparison can be inferred.

5. [Cline discussion #1727: Is it just me or Cline became more expensive?](https://github.com/cline/cline/discussions/1727) — original GitHub discussion, 2025-03
   Evidence: Different users report rising and falling expense. Original poster found smaller tasks helpful and described repeated unsolicited changes.
   Limit: Self-reports, different model/context/cache conditions. Ignore later promotional gateway replies.

6. [Kimi CLI discussion #926: Authorization failed](https://github.com/MoonshotAI/kimi-cli/discussions/926) — original GitHub issue discussion, 2026-01-27
   Evidence: CLI 1.1 report, later version reports, proposed fixes and one user's environment-variable resolution.
   Limit: No universal cause; historical incident rather than current availability assessment.

7. [Bolt blank-preview report with terminal logs](https://www.reddit.com/r/boltnewbuilders/comments/1uiqg4s/boltnew_stuck_in_this_message_your_preview_will/) — first-person report and support-style replies, 2026-07 (page relative date)
   Evidence: Original user posts actual Next.js errors; reply recommends stopping repeated prompting. A suggested downgrade produces a vulnerability warning in follow-up.
   Limit: Reply author's staff status not independently verified. Do not recommend the historical downgrade.

8. [WebContainer issue #1850: Missing Bolt integration](https://github.com/stackblitz/webcontainer-core/issues/1850) — original GitHub issue, 2025-05-03
   Evidence: Reporter describes import failures and invented UI instructions, with reproduction steps.
   Limit: Needs reproduction label; no confirmed root cause or current-state claim.

9. [Claude Code issue #44470: Change plugin scope from TUI](https://github.com/anthropics/claude-code/issues/44470) — original GitHub feature request, 2026-04 (search-relative date)
   Evidence: Reporter describes confusion between Project/Local/User plugin settings and manual JSON movement.
   Limit: Not a systematic beginner study; no claim about current fix status.

10. [Simon Willison: First run the tests](https://simonwillison.net/guides/agentic-engineering-patterns/first-run-the-tests/) — independent practitioner guidance, accessed 2026-09-23
   Evidence: Explains why starting with existing tests teaches agents the project's validation path.
   Limit: Expert practice, not controlled novice evidence.

11. [METR: Early-2025 AI and experienced developer productivity](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/) — original randomized study, 2025-07-10
   Evidence: Experienced maintainers on familiar repositories took longer with then-current AI despite perceiving a speedup.
   Limit: Authors explicitly caution against generalizing to most development, future models or other domains.
