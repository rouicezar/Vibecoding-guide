# 新站视觉规范：克制的技术工程风格

状态：根据用户 2026-09-23 明确指定的 OpenRouter、Hugging Face、GitHub 参考固定方向。以下尺寸与配色为本项目设计决定，不是对参考站 CSS 的复制或测量。后续页面共用本规范；尚未实现或完成视觉验收。

## 1. 风格目标

精致来自清楚的对齐、稳定的层级、合适的信息密度和统一的图标。视觉像一个可靠的技术产品，文字对完全不懂代码的人友好。

固定采用灰白中性色底、细描边、少量强调色、紧凑导航、舒展正文、适度圆角和功能性微交互。首期默认浅色；深色作为后续一致性任务，不影响首期交付。原词典深色暖棕配色属于旧版参考，不作为新站配色约束。

不使用大面积渐变、霓虹、玻璃模糊、悬浮光球、粒子、3D 装饰、滚动劫持、连续自动播放动画。首页不做占满首屏的宣传大字与空白；首屏应能开始解决问题。不用代码雨或终端外观制造技术感。

## 3. 布局骨架

### 全站

顶栏高 60px，只放品牌、全站搜索与阅读帮助；左侧全站导航逐项列出首页与 11 个内容板块。模块名称与顺序按 [页面与内容架构](page-content-architecture.md) 固定，不再用四组导航替代独立板块。

页面框架最大宽度 1440px，外边距 24px（手机 16px）；左导航 216px、可选右目录 176px、列间距 24px。阅读正文最大 760px；目录与概览使用剩余宽度，主内容允许收缩。统一 4px 间距基准，主要间距用 8/12/16/24/32/48px。

左导航只负责全站板块，板块内部分类放主内容顶部或可展开的筛选区，长文右侧目录只负责当前页面。当前位置用文字和明确选中态，不仅依靠颜色。

### 首页

主标题固定为“AI 时代，即使零基础不懂代码，也能 Vibe Coding。”，副标题为“从一个想法开始，学会和 AI 说清楚，一步步做出能用的网站和应用。”。标题在窄屏自然换行，不缩成小字。

正文顺序为主张与说明、搜索与网站入门主操作、11 个板块完整目录、当前卡点入口、一个完整示例。四类项目比较卡放项目分类页。主标题 36px，移动端 28px；不用巨幅 Hero。每个板块目录卡显示小图标、中文标题、专业名称与一句用途，不填虚假热度、用户数或完成率。

### 目录页

桌面保留 216px 全站导航，结果区上方使用分类条和筛选工具条，不再增加第二个常驻左栏。页头包含标题、说明和真实结果数量；下方工具条包含搜索、当前筛选与清除操作。首期排序仅使用真实字段，例如名称或更新时间，不造“最热门”。

术语和排查优先使用列表；视觉组件用预览卡片，两到三列按内容区宽度自适应，窄屏一列。卡片不强制和旧版一样固定 500px 高；详情承载完整提示词，避免每张卡嵌多层滚动。

### 内容详情

宽屏为全站导航 / 正文 / 页内目录三栏：左 216px、正文最大 760px、右 176px，间隔 24px。正文使用简短面包屑、标题、摘要、步骤、话术区、验收与下一步。右栏只放目录和关联入口，不堆无关推荐。

模板页使用正文说明加编辑/结果分区，手机按“填写 → 预览 → 复制”顺序排列。排查页只突出当前步骤与下一步，完整路径按需展开。

### 响应式规则

1200px 以下隐藏详情右目录或改为折叠块；960px 以下全站导航收进菜单，板块筛选放正文顶部；640px 以下卡片改一列、搜索保留显眼入口。弹出面板需要正确焦点与关闭行为，正文不能被永久覆盖。

360px 到 1440px 均须检查，200% 缩放不丢失关键内容。工程风格可以紧凑，触控目标仍以至少 44px 可点击范围为设计目标。

## 4. 首版设计 token

| 用途 | 值 | 使用规则 |
| --- | --- | --- |
| 页面底色 | `#FFFFFF` | 阅读与主内容 |
| 次级背景 | `#F6F8FA` | 工具条、演示背景、次级区域 |
| 主文字 | `#1F2328` | 标题和正文 |
| 次级文字 | `#59636E` | 摘要、说明、元信息；不进一步降透明度 |
| 分隔线 | `#D1D9E0` | 1px 结构边界，不代替控件焦点 |
| 控件边界 | `#818B98` | 输入框等需清楚识别的边界 |
| 强调色 | `#0969DA` | 链接、当前项、焦点和关键动作 |
| 强调背景 | `#DDF4FF` | 选中与信息提示的浅底 |
| 成功 | `#1A7F37` | 配文字或图标，不单独靠颜色 |
| 警告 | `#7D4E00` | 配浅色背景和明确说明 |
| 错误 | `#CF222E` | 失败、字段错误 |
| 按钮 / 输入圆角 | 6px | 统一，不随页面改变 |
| 面板 / 卡片圆角 | 8px | 标签允许胶囊，不全站大圆角 |
| 阴影 | 默认无；浮层轻阴影 | 不用阴影替代信息层级 |

浅色正文与交互状态在实现时检查对比度；普通文字目标至少 4.5:1，大字和必要控件边界至少 3:1。token 是起点，透明度、覆盖背景和禁用状态仍须逐项验证。

主按钮蓝底白字，次按钮中性描边，普通链接蓝色并在悬停/焦点时有明确提示。同一区域只有一个视觉主操作。危险操作使用红色语义，不能与普通主操作混用。

## 5. 字体与层级

系统无衬线字体优先：system-ui、-apple-system、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif；无需为了风格增加远程字体请求。

正文 16px / 行高 1.75；导航和列表辅助文字 14px / 1.5；元信息 12–13px；详情主标题 30–32px / 1.3；二级标题 24px；三级标题 18px。字重主要为 400/500/600，不全屏加粗。正文每行约 32–42 个汉字，长话术换行，不让横向滚动阻止阅读。

中文为主标题，英文专业术语在同一标题区作为次级文字，下方直接显示一句白话解释。解释不是只能悬停才出现；正文首次出现专业词时就地解释，进一步内容按需展开。等宽字体仅用于英文标识、快捷键或编号，不把大段中文话术渲染成代码块。话术区用“可以这样告诉 AI”标题与可复制面板。

## 6. 图标

统一使用 [Lucide](https://lucide.dev/guide/) 线性 SVG，按需引入；原生 Astro 区域静态输出，React 区域使用对应组件。禁止混入不同描边风格、装饰性 emoji 或随机图标字体。

通用图标 16px，导航 18px，主要入口 20px；采用一致 2px 描边并在实际尺寸检查清晰度。图标与文字间距 8px，视觉居中，不机械依赖字符基线。

| 板块 | 图形语义 |
| --- | --- |
| 首页 | 房屋 |
| 项目分类 | 分组网格 |
| Web 站点开发 | 浏览器窗口 |
| 手机 App 开发 | 手机 |
| 桌面 App 开发 | 显示器 |
| 和 Agent 沟通 | 对话 |
| 技术栈选择 | 分层结构 |
| 前端与 UI | 面板布局 |
| 后端 | 资料存储 |
| 测试 | 检查清单 |
| 部署上线 | 上传 / 发布 |
| 运维 | 设置 / 维护 |

具体导出名称在依赖锁定时核对，语义固定不随页面改变。主要导航保留文字；纯图标按钮需可访问名称和清楚的提示。装饰图标不重复朗读。同一动作使用同一图标和文案，例如复制始终为复制符号加“复制”。

## 7. 交互与状态

悬停通过浅底、边框或文字变化表达，不放大整卡或让布局跳动。过渡 120–180ms，仅限状态反馈；尊重减少动态效果偏好。当前导航项用浅背景及字重/边标识，页内同级视图使用细下划线 Tabs。

所有控件设计 default、hover、focus、disabled、loading、success、error 中适用的状态。焦点环使用 2px 强调色且不被裁切。提示文字不能只在鼠标悬停时可见。

复制成功必须由实际结果触发，并通过可访问状态消息反馈；失败保留原文和手动复制入口。表单错误贴近字段且给出修改方法。加载骨架只用于真的需要等待的区域，静态正文不人为增加等待。

## 8. 后续视觉验收

- 首页首屏能辨认站点用途、搜索和至少一个任务入口。
- 12 个板块共用顶栏、字体、间距和图标语言，内容类型决定布局而不是每页另创风格。
- 目录能迅速辨认标题、用途和元信息，正文保持舒适行宽。
- 360/768/1024/1440px 核对排版；键盘、缩放、长中文和空结果不破坏层级。
- 对比度、焦点、触控面积和反馈真实性有验证记录。
- 先核对首页、项目分类、Web 路线、UI 目录、Tabs 详情五种 [线框](layout-wireframes.md)，再用可操作原型检查布局与内容层级。

本规范已固定方向；未来若改变强调色、图标库或布局骨架，应更新本文件并检查全站一致性，不能在单页临时漂移。
