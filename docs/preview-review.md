## 验证

- `npm run check`：0 errors、0 warnings、0 hints。
- `npm run build`：12 个语言页面和根重定向构建成功。
- `npm run verify`：12 页语言标识、对应语言链接、唯一 H1、内部链接、资源和页内锚点通过。
- 浏览器访问全部 12 页；桌面四种详情和英文页面无整页横向溢出。
- 尺寸检查：320px 英文详情及中文首页、768px 中文首页、1024px 英文详情、1440px 桌面页面。没有声称所有页面所有尺寸均穷举。
- 实际操作：Mac 平台说明显示；中文详情切换对应英文详情；英文提示词复制显示 Copied；搜索无匹配显示空结果；手机菜单可打开和关闭。
- 浏览器错误日志为空。截图保留当时实际页面，应用内部小界面明确标注为示意。
