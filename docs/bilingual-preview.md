# 双语与视觉预览

本阶段交付：首页、项目分类总览、Web、小程序、手机 App、桌面 App，共六种页面，提供完整简体中文与英文版本（12 个地址）。其他模块保留独立导航，以明确的准备中说明呈现。

## 语言规则

- 中文使用 `/zh-cn/`，英文使用 `/en/`；根地址进入中文。
- 切换语言保留当前页面；标题、说明、按钮、表单、提示词和无障碍标签同步翻译。
- 专业术语始终配可见的白话解释。英文内容自然表达，不逐字硬译。
- 同一内容以稳定标识关联两种语言；缺失翻译不能用中文冒充英文版本。
- 页面提供对应语言的 alternate 链接，正式域名确定后再配置 canonical。

## 视觉与交互

沿用已定的白底、细边框、蓝色强调色和线性图标。桌面左侧十二板块导航，顶部搜索与语言切换；小屏幕改为菜单。首页以主张、开始入口和内容目录建立层级。分类总览以四种项目卡片和对比表呈现。详情以示意图、适用条件、步骤、提示词和检查清单呈现。

平台选项切换说明；步骤可展开；提示词可复制；搜索只检索本阶段已制作页面。示意界面不冒充实际产品，检查清单是用户自检而非自动测试结果。

## 技术边界

采用 Astro + TypeScript + Lucide。当前交互采用轻量浏览器脚本；React islands、全文检索及内容集合留到对应功能实施。本阶段为可交互设计预览，不代表完整课程或正式发布。
